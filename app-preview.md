## Key Features Visible:

1. **Header**: App title with Import/Export buttons
2. **Add Transaction Form**: Easy input with date picker, type selector, category, amount, and description
3. **Summary Cards**: Real-time statistics showing total income, expense, and balance
4. **Transactions List**: Chronological list with search and filter capabilities
5. **Color Coding**: Green for income (+), Red for expense (-)
6. **Actions**: Delete button for each transaction

## Color Scheme:
- Gradient header: Purple to violet (#667eea to #764ba2)
- Income card: Green gradient
- Expense card: Red gradient
- Balance card: Blue gradient
- Clean white background with subtle shadows
