# electron-study
데스크톱 앱 공부용

A basic Electron desktop application for learning purposes.

## Getting Started

### Prerequisites
- Node.js (v20 or higher)
- npm (v10 or higher)

### Installation

```bash
npm install
```

### Running the App

```bash
npm start
```

## Project Structure

- `main.js` - Main process (backend)
- `preload.js` - Preload script for secure IPC
- `index.html` - Renderer process (frontend UI)
- `package.json` - Project configuration

## Features

- ⚡ Fast and lightweight
- 🔒 Secure with context isolation
- 🎨 Beautiful gradient UI
- 📊 Displays Chrome, Node, and Electron versions
